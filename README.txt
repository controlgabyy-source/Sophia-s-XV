SOPHIA'S QUINCEAÑERA WEBSITE — HOW TO OPEN IN VS CODE

1. Download the ZIP file.
2. IMPORTANT: Extract/unzip it first. Do not try to edit the website while it is still inside the ZIP.
3. Open Visual Studio Code.
4. Click File > Open Folder.
5. Select the extracted folder named: sophia-quinceanera-site
6. In the left Explorer panel, click index.html.
7. To preview:
   - Best option: install the "Live Server" extension, then right-click index.html > Open with Live Server.
   - Or double-click index.html from Finder/File Explorer to open it directly in your browser.

Keep the assets folder beside index.html. The photos will not appear if the assets folder is moved somewhere else.
